CRITICAL DEPLOYMENT INFORMATION

PORTS:
  Development:
    Frontend:  4200
    Backend:   8000
    MySQL:     3306 (exposed for local access)
  
  Production:
    Nginx:     80, 443
    Backend:   9000 (internal, via PHP-FPM)
    MySQL:     3306 (internal only)

ENVIRONMENT VARIABLES (MUST SET):
  DB_HOST, DB_USERNAME, DB_PASSWORD
  APP_KEY (generate: php artisan key:generate)
  ADMIN_INVITE_CODE (security important!)
  ADMIN_ALLOWED_DOMAINS
  FACEBOOK_APP_ID, FACEBOOK_APP_SECRET (if using OAuth)
  TWILIO credentials (if using SMS)
  MAIL_* settings

DATABASE:
  Total Migrations: 38
  Key Features: Soft deletes, audit logging, many-to-many relationships
  Performance: Indexes on frequently queried tables
  Automatic: Migration runs on deployment via migrate service

SERVICES:
  Development (3): frontend, backend, mysql
  Production (4): nginx, backend, frontend (static), mysql
  Plus: migrate service (one-time execution)

DEPLOYMENT PROCESS:
  1. Configure .env in servetrack-backend/
  2. Run: docker-compose -f docker-compose.prod.yml build
  3. Run: docker-compose -f docker-compose.prod.yml up -d
  4. Verify: Check logs and test endpoints
  5. Setup: SSL certificate, Nginx configuration

BACKUP STRATEGY:
  - Daily database exports
  - Volume snapshots
  - Git commits for code
  - 30-day retention minimum
